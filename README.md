📈 Exploration des performances des employés

Dans le cadre du notebook “12 Projets pour devenir Data Analyst” de Natacha N., j’ai travaillé avec Desty sur un projet d’analyse des performances des employés.

🎯 Objectif
 Étudier les scores de performance et les heures travaillées pour détecter des leviers d'amélioration.

🛠 Compétences mises en œuvre
 ✅ Statistiques descriptives : moyenne, médiane, quartiles, variance, écart-type
 ✅ Visualisation des données : histogrammes, boxplots, bar charts, pie charts
 ✅ Détection et analyse des outliers
 ✅ Manipulation de données avec Python & Pandas

🔍 Observations
➡ Les projets spéciaux sont un levier clair de performance : Il serait pertinent d'encourager la participation à ces projets pour les profils Fully Meets (pleinement satisfait).

➡ L’engagement est corrélé à l’implication : Favoriser des initiatives RH axées sur la reconnaissance et les challenges transverses.

➡ Surveiller les absences dans certains départements : Des corrélations négatives avec la performance peuvent révéler un problème de climat ou de motivation.

Un projet qui m’a permis de mieux comprendre les dynamiques RH via la data et d’appliquer des méthodes d’analyse exploratoire concrètes.
